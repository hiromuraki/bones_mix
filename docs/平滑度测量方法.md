# 平滑度（Smoothness）指标怎么测量？

在 3D 人体姿态估计中，平滑度（通常也被称为 **Jitter** 或 **Acceleration Error**）是衡量动作“抖不抖”的核心指标。

它的底层物理逻辑极其简单：**如果一个人在真实世界中运动，他的关节点是不可能发生瞬间的“瞬移”和“高频震荡”的。** 换句话说，骨骼点的**加速度（Acceleration）**应该尽量小且连贯。

在数学和代码上，平滑度就是计算 3D 坐标的**二阶导数（即离散差分）**。

假设 $\mathbf{p}_{j}^{(t)}$ 表示第 $j$ 个关节点在第 $t$ 帧的 3D 坐标向量 $(x, y, z)$：

1. **第一步：算速度（一阶差分）**
    当前帧减去上一帧，就是关节点的移动速度：
    $$\mathbf{v}_{j}^{(t)} = \mathbf{p}_{j}^{(t)} - \mathbf{p}_{j}^{(t-1)}$$
2. **第二步：算加速度（二阶差分）**
    当前速度减去上一帧的速度，就是加速度：
    $$\mathbf{a}_{j}^{(t)} = \mathbf{v}_{j}^{(t)} - \mathbf{v}_{j}^{(t-1)} = \mathbf{p}_{j}^{(t)} - 2\mathbf{p}_{j}^{(t-1)} + \mathbf{p}_{j}^{(t-2)}$$
3. **第三步：求均值（最终的 Smoothness 指标）**
    计算整个视频（$T$ 帧）所有关节点（$J$ 个点）加速度的 L2 范数（几何距离）的平均值：
    $$\text{Smoothness} = \frac{1}{T-2} \sum_{t=3}^{T} \frac{1}{J} \sum_{j=1}^{J} \left\| \mathbf{a}_{j}^{(t)} \right\|_2$$

**结论：** 这个算出来的数值越小，说明你的模型预测出来的 3D 骨架越丝滑、越没有毛刺。在写论文时，对比别人的模型，你的平滑度指标如果大幅下降，这就是非常有说服力的数据。
