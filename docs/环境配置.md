# 环境配置

## 1. Conda

```bash
conda create -n bones_mix python=3.8.10 -y
```

## 2. CUDA 与 PyTorch

```bash
pip install torch==2.0.0 torchvision==0.15.1 torchaudio==2.0.1 --index-url https://download.pytorch.org/whl/cu118
```

```bash
conda install -c conda-forge cudatoolkit=11.8.0 cudnn -y
```

此外，还需要配置 `LD_LIBRARY_PATH`，将 Conda 环境目录添加到动态链接库搜索路径，以让程序能搜索 CUDA 环境:

```bash
export LD_LIBRARY_PATH=$CONDA_PREFIX/lib:$LD_LIBRARY_PATH 
```

## 3. RTMPose

```bash
conda install pytorch torchvision torchaudio pytorch-cuda=11.8 -c pytorch -c nvidia -y
```

**使用 MIM 安装依赖库 (MIM 会自动处理复杂的 C++ 编译环境):**

```bash
pip install -U openmim

mim install mmengine
mim install "mmcv>=2.0.0rc4,<2.2.0"
mim install "mmdet>=3.0.0,<3.3.0"  # 需要 mmdet 来做人体框检测
mim install "mmpose>=1.0.0" # 主角登场
```
